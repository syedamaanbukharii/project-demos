AI Travel & Coupon Discovery Agent — Interactive Demo

Multi-step tool calling: search flights & hotels, discover the best coupon, book and cancel — with the tool trace visible.

About this demo: runs fully in your browser with a fictional inventory. In the real agent an LLM decides which tool to call; here a rule-based intent parser stands in for the LLM, but the tool layer is real code: deterministic flight/hotel search, coupon eligibility and best-discount selection, booking state, and a date-based refund policy on cancellation. Every session keeps its own state, like the concurrent-session backend.
